# Jobhunt Fullstack

Monorepo aplikasi Express dan React yang dikelola dengan Bun.

## Prasyarat

- Bun 1.3 atau lebih baru

## Instalasi

```sh
cd backend
bun install

cd ../frontend
bun install
```

## Menjalankan aplikasi

Jalankan di terminal terpisah.

Backend:

```sh
cd backend
bun run dev
```

Frontend:

```sh
cd frontend
bun run dev
```

Endpoint pemeriksaan backend: `http://localhost:3000/api/health`.
